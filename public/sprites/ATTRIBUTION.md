# OpenAIP Sprite Attribution

The generated sprite files in this directory are derived from OpenAIP's public map resources:

- Source: https://github.com/openAIP/openaip-map-resources
- Project: https://www.openaip.net
- License stated in the source repository: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
- License text: https://creativecommons.org/licenses/by-nc-sa/4.0/

These assets were generated for visual compatibility with OpenAIP's current aviation map style. If Halo is used commercially, replace these sprites with commercially licensed equivalents or obtain explicit permission from OpenAIP.

## Commercial-use gate

Halo keeps these authentic OpenAIP sprites active for launch-readiness testing because they match the OpenAIP vector style. A paid, commercial, or revenue-generating launch is blocked until written OpenAIP permission is obtained or the sprite set is replaced with assets Halo can use commercially.

See `docs/legal/openaip-commercial-permission.md` for the checklist that must be completed before commercial release.
